# Сайт о Linux (linux-site)

Учебный проект по языку программирования JavaScript на стеке **Node.js, Express.js,
MongoDB, EJS**. Проект реализован по учебному пособию «Программирование: учебный
проект на JavaScript» (Москалева Ю.П., Симферополь, 2024). Вместо героев-котов в
качестве контента используются дистрибутивы Linux: **Ubuntu, Arch Linux, Fedora**.

Дизайн выдержан в тёмной терминальной теме с зелёными акцентами — по стилистике
сайта [my-template](https://github.com/zhabka638/my-template) (шаблон Landed от
HTML5 UP с кастомной linux-theme.css).

## Стек технологий

- **Node.js** — среда выполнения JavaScript вне браузера, поставляется с npm.
- **Express.js** — модуль Node.js для реализации web-сервера.
- **MongoDB** — документоориентированная база данных.
- **EJS** — шаблонизатор, структурирующий веб-страницы.

## Структура проекта (модули)

Каждый модуль находится в отдельной ветке git и наращивается поверх предыдущего:

1. **Введение** — описание стека технологий.
2. **Сервер на express** — стартовый проект express-generator (ejs).
3. **MongoDB** — консоль mongo, команды `find`/`update`.
4. **Маршрутизаторы и шаблоны** — ejs-locals, layout, шаблон дистрибутива.
5. **Навигация** — терминальная тема и навигационное меню (вместо Bootstrap —
   собственная linux-theme.css по стилистике my-template).
6. **Модуль mongodb** — подключение базы данных, модуль данных, посев в `tc2024`.
7. **Модуль mongoose** — ORM, схема, модель данных `Distro`.

> Модуль 5 в пособии учит подключению Bootstrap. Здесь Bootstrap заменён на
> собственную терминальную тему, чтобы проект соответствовал стилистике my-template.

## Запуск

```bash
npm install
npm start
```

Сервер поднимается на http://localhost:3000/

Доступные маршруты: `/`, `/ubuntu`, `/arch`, `/fedora`.

## Посев базы данных (модуль 6)

Запустите MongoDB на `localhost:27017`, затем:

```bash
node createDB.js
```

Создаёт базу `tc2024` и коллекцию `distros` с тремя документами.
