# Изображения дистрибутивов

Шаблоны ссылаются на логотипы дистрибутивов:

- `ubuntu.png` — Ubuntu
- `arch.png` — Arch Linux
- `fedora.png` — Fedora

Согласно учебному пособию, картинки выбираются в интернете и кладутся в эту папку.
Файлы не входят в репозиторий — добавьте их самостоятельно. Без них страницы
`/ubuntu`, `/arch`, `/fedora` рендерятся, но изображения будут неразмечены.
